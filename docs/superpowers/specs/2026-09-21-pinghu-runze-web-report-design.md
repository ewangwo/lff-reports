# 平湖润泽调研报告网页设计

## 目标

将《平湖润泽：浙江IDC与算力产业及合作落地调研报告》转换为一页式、可公开访问、来源完整的 GitHub Pages 阅读页面。页面服务于管理层决策、合作洽谈和项目尽调，先帮助读者快速取得结论，再保留完整论证和来源。

## 公开边界

- 公开完整网页和外部来源链接。
- 不提供 Word 或 Markdown 下载。
- 不加入账户、持仓、联系方式或其他私人信息。
- 不把未核实的规划、意向或行业推算写成已发生事实。

## 信息结构

页面采用“5分钟决策摘要 + 30分钟完整研究”双层阅读路径：

1. Hero：报告标题、核心判断、研究日期、版本、篇幅和资料范围。
2. 决策摘要：七项关键结论、建议的首个行动和关键指标全景。
3. 对象与边界：法律实体、总部与园区分工、资产和责任边界。
4. 区域格局：平湖在浙江及长三角的位置、代表性竞争和合作主体。
5. 商业机制：四种业务模式、资产流、资金流、服务流和客户数据流。
6. 证据与案例：政府、运营商、AIDC交付、电网、高校和REIT案例。
7. 合作优先级：高密度机电、集群优化、客户联合交付和资本合作的条件。
8. 90天路线图：分阶段行动、目标、输出物和停止条件。
9. 风险与尽调：20项信息清单、风险分级、证据缺口和验证方式。
10. 来源附录：27项来源按主题分组，正文引用可跳转，来源链接可打开。

桌面端使用粘性侧边目录；手机端使用折叠式顶部目录。宽表在小屏横向滚动，关键表格另提炼为卡片，避免只有表格才能获得核心结论。

## 视觉系统

- 风格：严谨的商业研究报告，采用纸张暖白底色、深海蓝信息层和橙色行动强调。
- 字体：系统中文无衬线用于正文，衬线字体用于少量标题和结论引语，确保无需加载外部字体。
- 视觉形式：指标卡、实体关系图、里程碑时间线、业务模式矩阵、四流图、优先级矩阵、90天路线图和风险清单。
- 证据标签：`已披露事实`、`管理层表述`、`本报告判断`、`合作建议` 使用稳定颜色和文字双重标记，不能只依赖颜色。
- 动效：仅保留目录定位、高亮和轻量进入效果，并尊重 `prefers-reduced-motion`。

## 内容与数据流

唯一内容源为已完成的 Markdown 报告。生成步骤读取 Markdown，转换标题、段落、列表、引用、表格和来源链接，再将其装配进静态 HTML。首屏指标和可视图形从报告中人工选取，所有数字继续保留口径、时间和来源编号。页面不请求后端数据，也不依赖运行时框架。

## 页面组件

- Hero 与元数据徽章：说明对象、日期、用途、版本和来源范围。
- Key metrics：展示 8–12 个带口径的关键数字。
- Sticky navigation：按决策顺序定位到章节，并随滚动高亮。
- Evidence badge：统一表示证据属性。
- Visualization blocks：使用 HTML/CSS 构建关系图、时间线和矩阵。
- Research body：完整承载报告所有章节、表格和来源标记。
- Provenance footer：说明来源、生成日期、公开页面地址和内容边界。

## 容错与可访问性

- JavaScript 失效时，全部内容仍可阅读和通过锚点导航。
- 外部来源在新窗口打开，并添加安全的 `rel` 属性。
- 使用语义化标题、跳转链接、可见焦点、足够对比度和打印样式。
- 对超宽表格提供滚动提示；在 375px 宽度下不得出现正文横向溢出。

## 验证标准

- 页面含原报告十章、附录A、附录B和全部来源编号。
- 至少包含三种可视化形式，实际目标为六种以上。
- 所有关键结论能区分事实、判断和建议。
- 内部锚点、来源链接、桌面和手机布局、打印样式均可用。
- 本地检查无本机绝对路径、无私人信息、无缺失来源标记。
- 推送后使用公网请求和真实浏览器确认页面为 HTTP 200 且主要内容可见。
