# IBKR 持仓估值与风险雷达

公开 GitHub Pages 仪表盘。它只展示公开市场研究数据，不包含 IBKR 账户号、真实持仓数量、成本、盈亏、订单或令牌。

页面刷新会绕过浏览器缓存读取仓库中的最新公开快照；上游行情和 SEC 数据由 GitHub Actions 定时刷新，因此刷新按钮不等于直接请求券商或实时行情接口。

## 信号口径

- A：最新调整收盘价低于 200 日简单移动平均线。
- B：两年价格分位和基于 SEC 可得日重建的 TTM PE 分位均不高于 10%。
- C：A、B 同时成立，显示“人工复核”，不自动形成交易建议。
- 数据缺失或过期时显示“数据不足”，不会当作未触发。
